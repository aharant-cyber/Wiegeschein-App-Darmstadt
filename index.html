Android App Integration

Standort Darmstadt – Digitales Wiegesystem

Um diese Web-App auf Ihrem Android-Gerät wie eine native App zu nutzen (inklusive Offline-Speicher, Kamera-/Unterschriften-Support und direktem PDF-Export), können Sie die Anwendung in wenigen Sekunden als Progressive Web App (PWA) direkt auf Ihrem Android-Startbildschirm installieren:

Installation auf Android (Chrome / Firefox)

  1. Öffnen Sie diese Wiegeschein-App im mobilen Browser auf Ihrem Android-Smartphone.
  2. Tippen Sie oben rechts auf das Menü-Symbol (die drei Punkte).
  3. Wählen Sie den Menüpunkt „Zum Startbildschirm hinzufügen“ oder „App installieren“.
  4. Bestätigen Sie die Installation. Danach erscheint das TEXAID-Logo direkt auf Ihrem Startbildschirm und öffnet sich als eigenständige App im Vollbildmodus!

Für die IT-Abteilung / APK-Erstellung (Cordova / WebView)

Falls Sie eine native .apk Datei für das unternehmensweite MDM benötigen, können Sie diesen Quellcode direkt in ein Android Studio Projekt (WebView Container) oder Apache Cordova einbetten:

cordova create TexaidApp com.texaid.darmstadt WiegescheinApp
# Kopieren Sie die optimierte HTML-Datei in /www/index.html
cordova build android
